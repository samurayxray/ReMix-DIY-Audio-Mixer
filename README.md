# ReMix-DIY-Audio-Mixer
I want to build a mixer for my PC with four faders, mute buttons and 6.35‑mm audio jacks.  I have taken apart a faulty mixer and photographed its boards so that I can spot parts that I might reuse.  Those parts still need to be tested.  I plan to design the circuit in KiCad and to make a 3D‑printed enclosure.
