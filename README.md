# ReMix. DIY Audio Mixer

I want to build a desktop mixer for my PC using parts recovered from an old AMPRO mixer where possible.

## My idea

The planned design includes four faders, buttons, 6.35 mm audio jacks and a 3D-printed enclosure. I want mixer handle audio and control application volumes on my PC. These functions will need circuits and software.

## progress

I have opened old mixer removed a four‑channel board and photographed both sides. Board contains faders, rotary potentiometers, buttons, LEDs, XLR sockets and jack sockets. Two capacitors failed in mixer. I am keeping power supply out of this project. Recovered components have not been tested yet. I also have not confirmed fader resistance values or pin connections.

## Circuit and enclosure

I plan to use KiCad for schematic and PCB and AutoCAD for enclosure. Enclosure dimensions and mounting holes will depend on components actually used.

## Next steps

- Identify and test one fader.

- Check buttons and audio sockets.

- Decide how audio circuit and USB controls will work.

- Draw schematic and prepare parts list.

- Measure components before designing enclosure.

## Status

Project is still, in planning and component‑checking stage. No working prototype yet.
