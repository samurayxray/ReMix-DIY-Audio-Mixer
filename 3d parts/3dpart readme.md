# ReMix DIY Audio Mixer – 3D Printed Parts

## Overview

This folder holds the 3D printable parts made for the ReMix DIY Audio Mixer**, a custom hardware project created during the **Hack Club Half Life** program.

The goal is to build a working audio mixer by combining electronics, reused parts, CAD design and 3D printing.

All 3D models are in STL format. Can be opened in slicing tools like Bambu Studio.

## 3D Printable Components

The current prototype has five sets of printable pieces.

| File               | Description                                                               |

| ------------------ | ------------------------------------------------------------------------- |

| `base.stl`         | The body that holds the electronics and internal wires.

| `Lid.stl`          | The top cover with space for sliders, controls and screws.

| `Bridges.stl`      | Eight small parts that help hold the audio faders in place.                  |

Tray.stl`         | A tray inside that keeps the circuit boards and modules stable.              |

Usb_retainer.stl` | A small piece that keeps the USB cable from pulling loose.                   |

## Enclosure Dimensions

The main case measures:

* Width: 190 mm

* Depth: 165 mm

* Height: 55 mm

* Wall thickness: 2.5 mm

The case is built to hold the mixer’s electronics, audio jacks, wiring and control parts.

## 3D Printing

### Recommended Equipment

**3D Printer:** Bambu Lab P1 Series

**Slicing Software:** Bambu Studio

**File Format:** STL

**Suggested Material:** PLA for testing

### Suggested Starting Settings

* Layer height: 0.20 mm

* Infill: 15–20%

* Wall loops: 3

* Supports: Use if needed based on part angle

* Build plate adhesion: Add a brim if parts don’t stick

These settings are a starting point. Adjust based on printer, material and shape.

## Assembly

The printed parts fit together to form the mixer’s frame.

The build process includes:

1. Printing all the parts.

2. Checking how well they fit.

3. Placing the tray.

4. Mounting the modules.

5. Adding the faders and controls.

6. Running wires inside.

7. Fixing the USB cable.

8. Attaching the cover.

##. Development

The original design was made using **Autodesk AutoCAD**.

Parametric CAD files were used so changes can be made easily later.

The STL files are for testing the layout before final build.
